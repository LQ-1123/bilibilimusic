> #27 已二次修正（2026-09-09）：第一次只改了空格 handler，复测仍失败；真正原因是**搜索下拉在输入法组合期间被 350ms 防抖 AJAX 重渲染**打断了候选窗口。现在的修法是「组合中不重渲染 + 下拉开着就不抢空格 + 搜索框改 `type=text`」。**请用最新打的包复测**。

| #33 | 播一首**多分 P 专辑**里的歌 → 点 ★ | 弹确认框说明「会取消该视频的 B 站收藏并移除专辑内全部曲目」 |
| #35b | 看播放条右侧 | ★ 与「词 / 队列 / 音量」按钮**等宽等高**（38×38），图标同为 SVG |

## 手机端（Android APK）

| # | 操作 | 期望 |
|---|---|---|
| #29 | 冷启 → 播放推荐池一首（试听流）→ 下拉通知栏 / 锁屏 | 显示**歌名 + 歌手 + 封面**；切下一首卡片跟着变；**点卡片回到 App** |
| #30 | 进任意 UP 主作品页 | 底部「主页 / 资料库 / 账号」**仍在**且可点 |
| #31 | 搜索 → 回车进结果页 | 封面是小方图（3 列），不再一张撑满整屏 |
| #32 | 搜索结果页 → 点底部 Tab；再进一次 → 用系统返回手势 | 都能退出；结果页顶部有「‹ 返回」按钮；退回主页后旧结果不残留 |
| #34 | 底部 Tab | 文案是「**资料库**」→ 点进去见「全部歌曲 + 各歌单（含曲数）」→ 点歌单进曲目列表 → **返回回到资料库**（不是主页），Tab 高亮仍在资料库 |
| #35a | 播歌 → 点封面进全屏播放页 | 歌名右侧有 ★，点击可收藏/取消，与歌词页的 ★ 状态一致 |
| #36 | 曲库里多分 P 的歌行 | 右侧有「**专辑**」按钮 → 点它进专辑（**不会误播那一首**）；专辑里每首的 ＋ 文案为「收藏到歌单」 |
| #37 | 搜索「周杰伦 合集」→ 回车 | 结果分 **UP 主 / 合集 / 歌曲** 三区；合集卡带「合集 · N 首」角标 |
| #37 | 点一个合集卡 | 建容器并直接打开 → 容器里列出全部子作品，每首右侧是「**收藏**」 |
| #37 | 在容器里点某一首的「收藏」 | 曲库**只多这一首**（不再一次进 50 首）；再点同一颗星可移出曲库（仍留在合集里） |
| #37 | 看合集容器的每行右侧 | 一颗**五角星**：未收藏=灰色空心，点一下变**粉色实心**并进曲库；再点变灰移出曲库（不再是文字「收藏」按钮） |
| 清除 | 歌单/曲库详情页每行 | **没有**「专辑」字样的小胶囊（当页顶部右侧的「专辑」标志按用户要求已移除） |
| #37 | 收藏一首合集中的歌后看左侧栏 | 「全部歌曲 / 我的曲库」计数**立即+1**并刷新（不再停留在旧数字） |
| #37 | 看曲库 / 最近收藏 | 合集里的未收藏子作品**不出现**；资料库与主页「专辑」区都能看到该合集 |
| 回归 | 手机端连切 主页 ↔ 资料库 ↔ 账号 ≥3 轮 | 无空白、无残留、无卡住 |

## 产物位置

- **桌面**：`desktop/src-tauri/target/release/bundle/macos/BiliMusic.app`（DMG 在 `bundle/dmg/`）
- **Android**：`android/app/build/outputs/apk/debug/app-debug.apk`

安装到手机：`adb install -r android/app/build/outputs/apk/debug/app-debug.apk`

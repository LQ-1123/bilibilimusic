# BiliMusic 验收手册（Acceptance Manual）

> 配套文档：`docs/issue-ledger.md`（问题台账与修法）——本手册按台账条目编号给出**可执行的验收步骤与通过标准**。
> 维护日期：2026-09-08 ｜ 原则：**修一条、验一条、勾一条**；所有验收均为手工可执行，不需要测试框架。

---

## 0. 怎么用

1. 先读「§1 环境准备」，把桌面/Android 双端构建起来；
2. 修完台账某条后，跳到本手册对应编号，按「操作 → 期望」执行；
3. **通过 = 期望全部满足**；任一不满足即失败，记到 §9 记录表（附环境/复现步骤）；
4. 建议按台账 §G 批次顺序验收（B0 → B1 → …），批内互相有依赖（例如 #14 依赖 F0 先过）。

符号约定：`[Android]`=Android 真机 ｜ `[桌面]`=macOS Tauri 壳 ｜ `[浏览器]`=Chrome/Edge 直接访问本地服务 ｜ `[PWA]`=手机浏览器安装 PWA。

## 1. 环境准备

- **桌面**：`desktop/` 下 `npm run dev`（或构建 dmg 安装）；后端 `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`。
- **Android**：真机 ≥2 台：**Android 15 + 手势导航**（必测）、**Android 13 + 三键导航**（必测）、如有 Android 8~11 抽查。
- **远程调试**：Android WebView 调试用 `chrome://inspect`（看 Network/Console/元素）——验证 #5 轮询、F0 流 URL 必需。
- **测试素材**（提前备好）：
  - 多分 P 合集视频链接（≥3P，如「陶喆合集」类）；
  - 一首歌名超长（>20 字）的歌曲；
  - 无任何歌词的歌曲、带 CC 字幕的歌曲、英文歌曲（LRCLIB 源）各一；
  - 登录态主账号一台设备；未登录态（游客）可临时用第二账号或退出验证。
- **回归基线**：动手前先跑 `python -m pytest -q` 与 `node --test tests/test_*.js` 确认全绿；验收结束后再跑一次。
